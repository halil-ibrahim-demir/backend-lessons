# C# Basics

Console applications and exercises covering the core building blocks of the C# programming language.

## 📁 Folder Structure & Topics

- [x] **`degiskenler/`** — Variables, data types, type casting, and basic console I/O
- [x] **`kontrol-yapilari/`** — Decision-making structures (`if-else`, `switch-case`) and logical operators
- [x] **`donguler/`** — Iteration statements (`for`, `while`, `do-while`, `foreach`)
- [x] **`diziler/`** — Single-dimensional and multi-dimensional arrays (matrices)
- [ ] **Methods & Overloading** — Method definitions, `ref` / `out` parameters, and method overloading *(Upcoming)*
- [ ] **Exception Handling** — Runtime error management with `try-catch-finally` *(Upcoming)*

## ▶️ How to Run

Open a terminal inside the target topic folder and run:

    dotnet run
