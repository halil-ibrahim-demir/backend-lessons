# Backend Lessons & .NET Roadmap

A structured learning and practice repository covering C# fundamentals, Object-Oriented Programming (OOP), relational databases, and ASP.NET Core Web API architecture.

## 📚 Learning Roadmap & Contents

### 1. C# Fundamentals (`csharp-basics/`)
- [x] **Variables, Data Types & Type Casting** (`degiskenler/`)
- [x] **Control Structures** — `if-else`, `switch-case` (`kontrol-yapilari/`)
- [x] **Loops** — `for`, `while`, `do-while`, `foreach` (`donguler/`)
- [x] **Arrays** — Single-Dimensional & Multi-Dimensional/Matrices (`diziler/`)
- [ ] **Methods, Parameters (`ref`, `out`) & Overloading**
- [ ] **Exception Handling** — `try-catch-finally`

### 2. Object-Oriented Programming (OOP) & Advanced C#
- [ ] Classes, Objects & Constructors
- [ ] Encapsulation & Properties (`get` / `set`)
- [ ] Inheritance
- [ ] Polymorphism & Abstract Classes
- [ ] Interfaces
- [ ] Collections (`List`, `Dictionary`, `HashSet`)
- [ ] LINQ (Language Integrated Query) Fundamentals
- [ ] Asynchronous Programming (`async` / `await`)

### 3. SQL & PostgreSQL
- [ ] Basic Queries (`SELECT`, `INSERT`, `UPDATE`, `DELETE`)
- [ ] Filtering & Sorting (`WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`)
- [ ] Table Relationships (`Primary Key`, `Foreign Key`)
- [ ] Joins (`INNER JOIN`, `LEFT` / `RIGHT JOIN`)

### 4. Entity Framework Core (ORM)
- [ ] Code-First Approach & `DbContext`
- [ ] Migrations & Database Updates
- [ ] One-to-Many (`1:N`) & Many-to-Many (`N:N`) Relationships

### 5. ASP.NET Core Web API & Architecture
- [ ] RESTful API Principles (`GET`, `POST`, `PUT`, `DELETE`)
- [ ] Controllers & Routing
- [ ] Dependency Injection (DI)
- [ ] Data Transfer Objects (DTOs) & AutoMapper
- [ ] Authentication & Authorization (`JWT - JSON Web Tokens`)
- [ ] Middleware & Global Exception Handling

## 🛠️ Tech Stack & Tools
- **Language & Framework:** C#, .NET, ASP.NET Core Web API
- **Database & ORM:** PostgreSQL, Entity Framework Core
- **Tools:** Visual Studio Code, Git & GitHub

## ▶️ How to Run
Navigate to the relevant project directory and run the console application:

    dotnet run
